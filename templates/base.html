{% comment %} Região de anúncio permanente. Sem ela, uma troca de HTMX é silenciosa para leitores de tela: a ação acontece e a pessoa não recebe sinal algum. Contrato para telas futuras (T8-11): toda resposta HTMX que precisar anunciar algo (sucesso, erro, validação) deve escrever aqui via hx-swap-oob, sempre acrescentando conteúdo dentro do contêiner — nunca substituindo o próprio elemento #anuncios. Um fragmento como `
Salvo
` troca o elemento inteiro e, se não repetir aria-live/aria-atomic/class="sr-only", mata a região viva silenciosamente. Use `Salvo` (ou innerHTML, se a tela precisar limpar o anúncio anterior): isso preserva os atributos do contêiner porque ele nunca é substituído. {% endcomment %}
